# Форма источника — не разрешение на подключение

| Поле | Заполнить владельцу |
|---|---|
| Source key / точный URL / канал | Не указан |
| Источник/владелец/контакт, если известен | Не установлен |
| Способ доступа | HTML / RSS / Telegram preview / разрешённый иной адаптер |
| Основание сбора | UNKNOWN; ссылка на конкретное разрешение/условия и дата проверки |
| AI-processing основание | UNKNOWN отдельно от collection |
| Ограничения хранения/повторного использования | Не установлены |
| Истечение/отзыв/ответственный | Не установлены |
| Allowed host/path/redirect scope | Не настроен |
| Предлагаемый диапазон/бюджет | Не утверждён |
| Полнота | Лента/анонс/полная статья/окно истории; total может быть неизвестен |
| Profile/selector version | Не создана |
| Dry-run | NOT_RUN |
| Collection validation | NOT_RUN |
| AI validation | NOT_RUN |

Поле approved ставится только в результате реального решения по конкретному источнику. Публичный канал не является самодостаточным основанием для AI. Условия Telegram и сайта нужно проверить применительно к способу использования; программная кнопка не создаёт прав.

## Минимальный пользовательский dry-run
Зафиксировать точную цель и отключённые фоновые задания → проверить права → указать ограниченный диапазон → запустить пробу адаптера → сопоставить полученные тексты с доступным источником → зафиксировать полноту/правки/пропуски → отдельно решить допустимость следующей AI-обработки.

AI validation не повышается успешной загрузкой HTML. Сбор не повышается успешным parse синтетического HTML. Не вписывать в шаблон реальные токены, session cookies или доступы.
