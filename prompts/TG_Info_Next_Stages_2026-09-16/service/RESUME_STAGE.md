# Продолжение в новой сессии Claude
Прочитай COMMON_RULES, текущие STATE/HANDOFF, конкретный stage prompt и фактический git diff. Определи, что уже сделано и что реально проверено. Большой контекст не разрешает выполнять все стадии.

Не повторяй migrations/seed/publish/merge и не запускай пользовательские операции. Не считать отчёт прежней сессии доказательством текущего исполнения при отличающемся diff. Выведи коротко текущий gate, оставшиеся задачи и безопасное первое действие; затем продолжи только незавершённую часть этого этапа.

При отсутствии результатов USER_RUN подготовить точные команды и остановить только зависимую валидацию. Не придумывать logs и не задавать повторно вопросы, ответы на которые уже есть в handoff. Заверши новым handoff по форме package/templates/HANDOFF.md.
