# Исправить замечания ревью текущего этапа
Работай как основной исполнитель. Прочитай текущий stage prompt, COMMON_RULES, diff и конкретный отчёт Codex. Не переходи на следующий этап.

Для каждого замечания: воспроизведи безопасно; если подтверждается — исправь минимальным diff и добавь regression; если не подтверждается — покажи функцию/тест/условие и причину. Не спорь только потому, что прежний тест был зелёным. Не делай рефакторинг вне влияющей области.

Не переименовывай исторические PASS, не меняй gold labels и security/scope gates ради прохождения. Запусти только разрешённые офлайн-проверки; пользовательские проверки пометь NOT_RUN. Обнови report/handoff списком finding→fix→test→result. Рабочие данные/секреты/flags/источники/model не трогать. Остановись для повторного read-only review.
