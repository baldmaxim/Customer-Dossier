# Материалы для приёмки

TEST_MATRIX.md / .json — предметные сценарии по этапам. SYNTHETIC_CORPUS.json — вымышленные короткие тексты и ожидаемые инварианты. Они помогают написать тесты, **но не являются готовым исполняемым suite**. Все проверки в момент выдачи пакета NOT_RUN.

Использовать только в изолированной тестовой БД. Не импортировать компании и события в рабочий справочник. Corpus не содержит реальных контактов, ИНН или юридических утверждений о существующих компаниях. При тестировании checksum использовать отдельные сгенерированные/разрешённые тестовые реквизиты и не объявлять их реальными организациями.

Для LLM-оценки не подавать `expected` вместе с входным текстом в extraction prompt. Expected хранится у test harness, а модель видит только тестовый материал и действующую схему. Не считать прохождением, если модель получила ответ прямо в context.

Раздельные результаты: детерминированные parser/verifier/storage tests; PostgreSQL integration; browser e2e; фактическая генерация настроенной локальной модели; live-source smoke при допуске. Синтетика не измеряет полноту парсинга всех Telegram-каналов, реальное качество на строительных публикациях или достоверность контрагентов.

Для полноценной оценки позднее нужен разрешённый размеченный корпус реальных материалов с разделением по семействам источников/событий, чтобы перепечатки не попадали одновременно в настройку и независимую проверку. Достигнутые проценты в этом пакете не заявляются.
