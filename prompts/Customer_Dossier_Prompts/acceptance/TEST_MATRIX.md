# Матрица приёмки

**Все сценарии при выдаче пакета имеют статус NOT_RUN.** Исполнитель реализует и запускает тесты в своей среде. Строки — минимальные требования, а не готовый тестовый runner. Базовые unit checks не заменяют integration PostgreSQL и реальную проверку модели.
