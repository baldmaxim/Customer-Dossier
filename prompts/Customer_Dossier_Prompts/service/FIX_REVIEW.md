# Исправление замечаний независимой проверки

Ты — основной исполнитель текущего этапа Customer Dossier. Прочитай COMMON_RULES.md, STATE.md, последний stage-report и независимый `<STAGE_ID>_REVIEW.md`. Проверь, что review относится к текущим файлам/версии. Выполни только исправления в пределах текущего этапа; будущие функции не добавляй.

Для каждого замечания: воспроизведи → добавь/уточни регрессионный тест → исправь причину → запусти конкретный тест и затронутые integration/builds. Не «чинить» удалением теста, понижением защиты, скрытым catch, unsafe cast/any или подстановкой фиктивных данных. Если замечание не подтверждается, покажи воспроизводимую проверку и аргумент; не ставь FIXED без кода/проверки.

Не перезаписывай чужие изменения, не сбрасывай Git и не меняй рабочую БД. В отчёте отдельная таблица review ID → confirmed/not reproduced → решение → тест/log. Все изменённые важные gates повтори. Сохрани прошлый review неизменным; новые результаты отдельной записью/отчётом с датой, обнови STATE/HANDOFF.

Остановись после исправлений. Независимая повторная проверка — отдельный запуск REVIEW_STAGE. Следующий stage, commit/push и рабочая миграция не разрешены этим промтом.
