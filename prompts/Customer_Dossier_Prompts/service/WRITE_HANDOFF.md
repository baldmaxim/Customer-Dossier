# Зафиксировать передачу контекста без новых изменений продукта

Не начинай новых функций. Прочитай COMMON_RULES.md, текущий stage prompt, STATE.md, фактический status/diff и результаты выполненных команд.

Обнови docs/development/HANDOFF.md по шаблону из пакета. Обязательно укажи: корень/среду; HEAD либо отсутствие Git; текущий этап/подшаг; список изменённых файлов; схемы/миграции и где они реально применены; active flags; состояние безопасного test-target; утверждённые решения/ADR; реально пройденные/непроверенные тесты; открытые дефекты; следующую конкретную безопасную операцию; запреты на рабочую БД, источники и Git writes. Не включай секреты и полные тексты источников.

Сохрани STATE.md и текущий stage-report. Не помечай незаконченный этап PASS ради передачи. Сформулируй краткое сообщение, которое пользователь может вставить новой сессии, с точными путями файлов. Никаких commit, push, переразбора и продолжения в следующем этапе.
