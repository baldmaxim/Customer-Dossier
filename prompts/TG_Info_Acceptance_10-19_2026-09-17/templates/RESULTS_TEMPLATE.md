Дата/часовой пояс: НЕ ЗАПОЛНЕНО.

## Сводка

| Направление | Вердикт | Основание | Что ещё требуется |
|---|---|---|---|
| Offline-код | NOT_VERIFIED | Исходный отчёт есть; логи сюда ещё не внесены | Сверить |
| Fresh install / upgrade | NOT_RUN | Нет результата | Пользовательский прогон |
| DB-интеграция | NOT_RUN | Нет результата | Общий набор и критические случаи |
| Recovery | NOT_RUN | Нет результата | Содержательное сравнение + приложение |
| Browser / печать | NOT_RUN | Нет результата | Реальный API и оператор |
| Производительность | NOT_RUN | Нет результата | Валидные ответы, ошибки, N, среда |
| Реальная конфигурация модели | NOT_RUN | Нет результата | Полный quality report |
| Поимённые источники | Пустой перечень | Нет результата | Профили/основания/проверки |
| Sharp | NOT_VERIFIED | Нет точного advisory в исходном сообщении | Triage и решение |
| Пилот | PILOT_NOT_RUN | Запуск не заявлен | Отдельное решение и фактический ограниченный запуск |

## Дефекты и пропуски

ID; подтверждённое поведение; evidence; влияние; severity; блокируемое действие; минимальное исправление; ответственный; повторная проверка. Отдельный раздел для NOT_RUN без установленного дефекта.
