# Индекс сквозной приёмки 10–19

Это дополнительный индекс, не замена исходным T10…T19 и USER_RUN. Все приведённые ниже результаты по умолчанию **NOT_RUN / NOT_VERIFIED в рамках этого пакета**. Агент обязан сопоставить их с фактическими тестами; уже имеющиеся пригодные журналы можно зачесть. Один общий сценарий допускает ссылки из нескольких этапов.

Обозначения: **O** — офлайн-код/документы; **D** — пользовательская БД; **B** — пользовательский браузер; **P** — пользовательские замеры; **M** — реальная модель; **S** — разрешённые источники; **H** — решение/проверка человека. Группа не является разрешением запуска.

## Минимальные границы решения

Нельзя принимать data-core без нужных D-проверок только по O. Нельзя принимать operator-flow по компонентным тестам без B. Нельзя утверждать LOCAL_MODEL_VALIDATED по mock; LIVE_SOURCE_VALIDATED — без поимённого S; выполненный пилот — без AC-41/AC-42.

Для выбранного небольшого пилота большой нагрузочный тест может быть отдельным открытым ограничением, если владелец заранее утвердил объём и обязательный сценарий устойчив на нём. Это не закрывает весь этап 18 автоматически. Обязательные критерии исходного проекта имеют приоритет; их не понижать молча.

Ограниченный pilot-review не превращает сбор в постоянное расписание и не разрешает автоматическую публикацию. Нельзя объявить полноту данных о всей компании/интернете по выбранным источникам.
