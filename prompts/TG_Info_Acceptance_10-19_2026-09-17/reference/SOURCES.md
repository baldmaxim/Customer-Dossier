## Первичная техническая документация

**S1 — npm audit.** JSON-диагностика, отправка dependency metadata в registry, omit и side effects fix/force. Документация v11 использована как справочная; конкретные команды следует сверять с npm в проекте.
`https://docs.npmjs.com/cli/v11/commands/npm-audit/`

**S2 — npm explain.** Назначение команды: цепочка, по которой пакет установлен.
`https://docs.npmjs.com/cli/v11/commands/npm-explain/`

**S3 — sharp, официальные advisories и security policy.** Есть несколько предупреждений; их наличие не устанавливает, какое относится к проекту. Нужны версия и ID из фактического audit.
`https://github.com/lovell/sharp/security/advisories`
`https://github.com/lovell/sharp/security`

**S4 — npm, описание audit reports.** Структура отчёта и сведения о severity/затронутых зависимостях.
`https://docs.npmjs.com/about-audit-reports/`

**S5 — PostgreSQL pg_dump.** Согласованный экспорт одной базы; объекты окружения/кластера рассматриваются отдельно. Рекомендованная в проекте остановка писателей нужна для сопоставления отдельно снимаемых baseline/manifest/dump.
`https://www.postgresql.org/docs/current/app-pgdump.html`

**S6 — PostgreSQL EXPLAIN.** ANALYZE выполняет запрос и его побочные действия. Поэтому такой замер не считать безусловно read-only.
`https://www.postgresql.org/docs/current/sql-explain.html`

Конкретную версию PostgreSQL в окружении пользовательского d33521b автор пакета не устанавливал. Ссылки на current не означают требования обновить СУБД или применить новые возможности.
