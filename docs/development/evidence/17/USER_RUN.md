# Пользовательский прогон этапа 17
**Это форма, а не выполненный прогон.** PowerShell, корень `TG_Info`. Тестовая цель — `127.0.0.1:55433/tg_info_test` с маркером.
Модель подменена шаблонными ответами; живые источники и LM Studio не нужны. Записывается не оценка интерфейса, а выполненные задачи
и найденные затруднения.
