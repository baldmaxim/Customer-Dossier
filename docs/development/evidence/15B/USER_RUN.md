Шаг 4, что проверить (синтетическая база после seed):
1. «Админка» → «Открыть запуски»: «Всего по фильтру» совпадает с числом запусков; фильтр «разобран частично» и «Дальше/Назад» работают.
   Выключенный исполнитель показан предупреждением, не скрыт.
2. Карточка неполного запуска (если в seed нет — пропустить с пометкой): у сбойного чанка видны исход и ошибка, набора нет.
3. «Повторить новым запуском» дважды: второй раз — «Повтор уже поставлен: #N», один новый запуск.
4. У поставленного запуска «Отменить запуск» → «Дальнейших вызовов модели по этому запуску не будет»; статус «отменён».
5. Completed-запуск с набором → «Предпросмотр публикации»: добавятся/снимутся/останутся с цитатами; предупреждения о решениях.
6. Не закрывая предпросмотр, во второй вкладке записать решение аналитика по утверждению прежнего набора этой публикации
   (или сменить ИИ-допуск источника в админке) → «Опубликовать этот набор»: при решении — «409 … откройте предпросмотр заново»,
   при отзыве допуска — «Не опубликовано: … Допуск …». Публикация не изменилась.
7. «Обновить предпросмотр» → «Опубликовать»: «Опубликовано…». В очереди проверки у доказательства есть ссылка «запуск #N»,
   открывает карточку этого запуска.
8. Остановить API и обновить страницу запусков: сообщение «Нет соединения с API…», а не «Запусков по фильтру нет».

Что передать: хвосты логов шагов 1–3 с exit code; по шагу 4 — пункты PASS/FAIL/NOT_APPLICABLE (скриншоты без токенов и cookies).
