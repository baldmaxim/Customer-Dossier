## Разбор A5

Причина — дефект проверки, а не теста: `isNameInQuote` сравнивал нормализованное имя (ё → е, «утес-демо») с цитатой,
где «ё» оставалась («Утёс-Демо»). Объект с «ё» в названии отбрасывался как «имя отсутствует в цитате» ещё до публикации —
то же происходило бы на живых текстах. Исправлено в `pipeline/verify.ts` (flatten сводит ё к е), добавлен unit-тест;
поиск объекта в интеграционном тесте не зависит от ё. Unit после исправления: 26 / 385. Нужен повторный прогон A5.

## Разбор J4 по счётчикам (JSON без ответов модели)

- SYN-08 «на проверку» 1: проверка отправляла на проверку иск, если модель назвала «о взыскании» присуждённой суммой. Теперь
  назначение понижается до требования без блокировки — факт иска не теряется.
- SYN-02 / SYN-12 «отброшено 2»: вероятная причина — объект участия в поле `object` вместо `project`. Теперь принимается,
  если это название объекта из того же ответа.
- SYN-01: публикуемых 3 (только упоминания) и «на проверку» 1 — модель, по-видимому, вернула договор Заказчик → Альфа
  (без признака договора) вместо участия. Это промах модели; проверка поступила верно.
- llm_error «HTTP 400 terminated» — обрыв на стороне LM Studio (SYN-09 шёл 289 с) при занятой VRAM.

Unit после поправок: 26 / 386. Отчёт замера теперь содержит `answer` и `reasons` — повтор J4 покажет точную причину.
