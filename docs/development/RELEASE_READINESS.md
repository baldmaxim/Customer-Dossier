## Границы заявления

- Проверено на синтетическом корпусе, созданном для этой проверки. Реальные тексты, реальные компании
  и реальная нагрузка не участвовали.
- «Миграции воспроизводимы» относится к пустой базе и к синтетической базе, накаченной до 009.
  Апгрейд рабочей копии пользователя не выполнялся и не заявляется.
- Сохранность данных ограничена сохранностью диска и регулярностью резервных копий; автоматических копий нет.
- Локальная модель не валидирована по полноте: пропуски фактов вероятны, и это видно в замере этапа 06.
- Итоговой оценки надёжности компаний нет; отсутствие сигналов не означает отсутствие проблем.

## Условия, при которых статус меняется

- **LOCAL_FIXTURE_READY → подтверждён по усиленным условиям**: пользователь прогнал `evidence/09/USER_RUN_CLOSURE.md`
  (G01, A–F) на одном состоянии кода: полный unit и интеграция без пропусков, `release:manifest` MATCH после restore и
  MISMATCH на негативном контроле, чтение копии через приложение, перезапуск процесса, отказ БД, валидный bench — и нет открытых
  дефектов целостности, изоляции тестовой цели или обхода доступа.
- **LOCAL_MODEL_VALIDATED → да**: повторный `npm run benchmark:model` на текущей схеме даёт приемлемую полноту
  при сохранении безопасности, и решение зафиксировано отдельным отчётом.
- **LIVE_SOURCE_VALIDATED → перечень**: для каждого источника — подтверждённый допуск с основанием, успешная
  проба и хотя бы один полный проход сбора без `parser_degraded`.
