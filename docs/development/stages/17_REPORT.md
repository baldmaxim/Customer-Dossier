## Контракт `negotiation-brief@1` (`backend/src/dossier/brief.ts`)
Строится детерминированно из досье `dossier-template@3`, без модели и сети.

Разделы: `identity` (юрлицо) → `object` (объект, корпус, работы) → `claimed_role` → `role_basis` (итог по статусу роли + основания)
→ `direct_client` (заявленный заказчик, итог по цепочке, договоры) → `terms` (со слов / из публикаций) → `contradictions_gaps`;
отдельно `background` («не события выбранной стройки»: события компании, договоры и роли вне предмета обращения, события объекта),
`questions`, `dataLimits`.

Пункт: `status` + `statusLabel` словами (`по публикации`, `проверено аналитиком`, `аналитик: спорно`, `отклонено аналитиком`,
`со слов обратившегося`, `не установлено`, `источники противоречат`, `контекст`), `text`, `scope` (из scope-match@1), `asOf`
(самая свежая публикация основания), `sources {publications, textFamilies, independence, label}`, `pendingRevision`, `assertionIds`, `evidenceIds`.

Происхождение: `single_publication`; `reprints_of_one_text` — «одно подтверждение»; `different_texts_origin_unknown` — «независимость
не доказана». Независимость не утверждается никогда: первоисточник публикаций не устанавливается.

Разрешённые unknown: «не установлено» (в выборке нет), «в источнике не указано: …» (scope), «первоисточник не установлен»,
«полнота выборки/качество разбора ограничены» (dataLimits). Запрещено (проверяется тестом): «ничего плохого не найдено», оценки
надёжности, рекомендации сотрудничать, риск-баллы, долг как установленный факт, «проверенный/подписанный договор».

## Совместимость, миграции, откат
Миграций нет. `dossier-template@3`: новые снимки содержат `brief` и поля фраз `sources`/`pendingRevision`; старые снимки неизменны
(hash прежний) и выгружаются с пометкой об отсутствии краткого досье. API досье — добавление полей. Откат — `git revert`: новые снимки
@3 останутся читаемыми прежним кодом (лишние поля игнорируются), история и решения не затрагиваются.

## Границы аналитики и открытые риски
- Происхождение: только число публикаций и семей одинакового текста; редакционная или причинная связь публикаций не выводится.
- Судебные сведения — роль компании в деле, стадия и сумма требований по публикации; юридические и финансовые выводы не делаются.
- `LOCAL_MODEL_VALIDATED` — константа кода; при решении по оценке модели меняется отдельным коммитом вместе с RELEASE_READINESS.
- «Есть более новая редакция» — по `source_items.latest_revision_id`; очередь переразбора (15B) нужно запускать вручную.
