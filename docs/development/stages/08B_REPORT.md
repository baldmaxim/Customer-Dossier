## Что изменилось для пользователя

- **Схема связей** на карточке компании, объекте и обращении: узлы-компании и объекты, рёбра с типом, направлением,
  корпусом, пакетом работ и периодом. Типы различаются штрихом линии и подписью; толщина и цвет ничего не значат.
  Фильтры: тип связи, глубина (1–3), корпус, период, «только проверенные», «включая планы, заявления и отрицания».
  Совместное упоминание по умолчанию выключено. Есть таблица с тем же содержанием. Выбор ребра открывает
  утверждение с цитатой, редакцией и историей решений. Путь А→Б→В никогда не рисует ребро А→В.
- **Снимки досье** на странице обращения: «Создать снимок» (можно с фильтром дат событий). Снимок открывается
  по адресу `/snapshots/:id`, показывает только хранимое содержание, подтверждение целостности, версии правил
  и шаблона, схему связей из снимка, решения аналитика, источники с цитатами и номерами редакций, ограничения.
- **Выгрузки из снимка**: «Версия для печати» (HTML, печать в PDF делает браузер), «Скачать Markdown», «Скачать JSON».
- **Отзыв допуска источника** после снимка: цитаты этого источника скрываются при выдаче и в выгрузках с объяснением;
  целостность хранимого содержания при этом подтверждена.
- **Вымарывание фрагмента** по обязательному требованию: цитата заменяется пометкой, основание и оба hash — в журнале.
